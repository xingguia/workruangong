# 管理后台使用说明

## 访问地址

http://localhost:8000/admin

## 登录

- 默认管理员: `admin` / `admin123`
- 支持回车键登录

## 功能模块

### 1. 仪表盘

- 总用户数、活跃用户(7日)、付费会员、本周新增
- 用户增长趋势图（支持 7天/30天/90天 切换）
- 日活趋势柱状图
- 最近注册用户表格
- 最新训练记录表格

### 2. 用户管理

- 搜索：按用户名、手机号模糊搜索
- 筛选：按会员状态筛选（VIP/普通）
- 分页浏览用户列表
- 点击用户名查看详情

**用户详情弹窗可编辑：**
- 用户名、性别、健身目标
- 身高、体重、体脂率、腰围、臀围
- BMI 自动计算
- 修改密码（至少6位）
- 开通/取消 VIP
- 封禁用户
- 确认保存修改

### 3. 训练数据

- **训练记录** Tab：查看所有用户的训练记录，支持搜索和日期筛选
- **训练任务** Tab：查看所有用户的训练任务
- 可删除单条训练记录
- 汇总统计：总记录数、今日新增、平均消耗

### 4. 数据统计

- **用户画像**：性别分布饼图、健身目标柱状图
- **训练行为**：热门动作 Top 10、训练类型玫瑰图
- **器材统计**：用户器材使用分布
- **留存分析**：次日/3日/7日/14日/30日留存率
- **会员转化**：VIP 转化率趋势

### 5. 内容管理

- 训练动作库管理（增删改查）
- 公告管理（增删改查）

### 6. 反馈管理

- 查看用户反馈列表
- 查看反馈详情和消息记录
- 回复用户反馈
- 更新反馈状态（待处理/处理中/已解决）
- 批量删除和批量更新状态

### 7. 系统设置

- 管理员账号管理（新增/删除，仅超级管理员）
- App 版本管理

## 操作说明

| 操作 | 方式 |
|------|------|
| 登录 | 输入账号密码，点击「登录」或按回车 |
| 退出 | 点击右上角管理员头像 |
| 搜索 | 输入关键词后点击搜索按钮或按回车 |
| 编辑用户 | 用户列表 → 点击用户名或「详情」→ 修改字段 → 确认 |
| 删除记录 | 训练数据页 → 点击记录右侧「删除」按钮 |
| 新增管理员 | 系统设置 → 管理员账号 → 「+ 新增管理员」 |

## 技术说明

- 单页面应用，原生 HTML/CSS/JS，无框架依赖
- 图表使用 ECharts 5.5（动态加载）
- Token 存储在 localStorage，支持自动登录
- 所有 API 请求携带 JWT 认证
