# 燃动时刻 - 管理后台设计规格书

## 一、整体结构

### 布局
```
┌──────────────────────────────────────────────┐
│  Sidebar (240px)    │   Header (固定顶部)      │
│                     │─────────────────────────│
│  · 仪表盘           │                         │
│  · 用户管理          │   内容区域                │
│  · 训练数据          │   (可滚动)               │
│  · 内容管理          │                         │
│  · 数据统计          │                         │
│  · 反馈管理          │                         │
│  · 系统设置          │                         │
│                     │                         │
└──────────────────────────────────────────────┘
```
- **色彩方案**：深色侧边栏 (`#1A1A2E`)，白色内容区，主色调沿用 App 橙色 `#FF6B35`
- **侧边栏**：Logo + 导航菜单，当前页高亮橙色
- **顶部栏**：管理员头像、通知图标、退出登录
- **响应式**：≥1280px 最佳，移动端侧边栏折叠为汉堡菜单

## 二、页面详细设计

### 页面 1：仪表盘 (Dashboard)

**布局**：4列统计卡片 + 2列图表 + 快捷操作区

**组件清单**：
| 组件 | 位置 | 说明 |
|------|------|------|
| 统计卡片 ×4 | 顶部一行 | 总用户数、今日活跃、本周新增、VIP会员数。每张卡片含图标、数字、环比变化（↑↓ 百分比） |
| 新增用户趋势图 | 左侧 2/3 | 折线图，横轴日期(近30天)，纵轴新增数，可切换 7天/30天/90天 |
| 日活趋势图 | 右侧 1/3 | 柱状图，近7天每天活跃用户数 |
| 快捷操作区 | 下方 | 3 个按钮卡片："新增管理员"、"查看最新用户"、"导出数据报表" |

**数据接口**：
```
GET /api/v1/admin/dashboard
Response: {
  total_users: number,
  today_active: number,
  week_new_users: number,
  vip_users: number,
  user_trend: [{date, count}],   // 近30天
  active_trend: [{date, count}]  // 近7天
}
```

### 页面 2：用户管理

**布局**：顶部搜索栏 + 筛选标签 + 用户表格 + 底部分页

**搜索栏**：
- 搜索输入框（支持手机号/用户名搜索）
- 筛选下拉：会员状态（全部/会员/非会员）、注册时间范围
- "搜索" 按钮 + "导出" 按钮

**用户表格列**：
| 列名 | 宽度 | 说明 |
|------|------|------|
| ID | 80px | 用户ID |
| 头像 | 50px | 圆形头像或首字母占位 |
| 用户名 | 120px | 可点击跳转详情 |
| 手机号 | 130px | |
| 注册时间 | 150px | 格式 yyyy-MM-dd HH:mm |
| 会员状态 | 80px | 标签：金色"VIP" 或 灰色"普通" |
| 健身目标 | 80px | 减脂/增肌/塑形/体态 |
| 最后活跃 | 150px | |
| 操作 | 120px | 按钮："详情"、"封禁" |

**点击用户名 → 用户详情抽屉/弹窗**：
- 基本信息：头像、用户名、手机号、性别、注册时间
- 身体数据：身高、体重、BMI、体脂率（最新 + 初始对比）
- 训练统计：累计训练次数、累计时长、累计消耗卡路里
- 会员信息：VIP状态、开通时间、到期时间、续费记录
- 操作按钮：开通VIP、重置密码、封禁账号

**数据接口**：
```
GET /api/v1/admin/users?page=1&page_size=20&keyword=&vip_status=&date_from=&date_to=
Response: { total, page, page_size, list: [...] }

GET /api/v1/admin/users/{id}
Response: { 用户完整信息 + 训练统计 }
```

**布局**：顶部筛选 + 统计摘要 + 记录表格

**筛选栏**：用户搜索 + 日期范围选择 + 训练类型下拉

**统计摘要**（一行3个卡片）：总记录数、今日新增记录、平均每次卡路里

**记录表格列**：
| 列名 | 说明 |
|------|------|
| ID | 记录ID |
| 用户 | 用户名 |
| 动作名称 | |
| 肌群 | |
| 组数 | |
| 次数 | |
| 重量(kg) | |
| 消耗(千卡) | |
| 时间 | |
| 操作 | 删除 |

#### 3b. 训练任务

**表格列**：ID、用户、任务名、日期、状态（未开始/已完成）、训练类型、组数×次数、创建时间

### 页面 4：内容管理

**子 Tab**：动作库 | 徽章管理

#### 4a. 动作库管理

**布局**：搜索 + 新增按钮 + 动作卡片网格（3列）或表格

**动作卡片/行**包含：动作名、所属肌群、类型、基础卡路里系数(cal/rep)、编辑/删除按钮

**新增/编辑弹窗**：
- 动作名称（文本框）
- 肌群分类（下拉：胸肌/背部/肩部/手臂/腿部/核心）
- 训练类型（下拉：力量/器材/有氧/HIIT/柔韧/核心）
- 基础卡路里系数（数字输入）
- 描述（文本域）
- 保存/取消

#### 4b. 徽章管理

**布局**：徽章列表（3列网格），每张卡片含图标、名称、解锁条件描述、当前拥有用户数、编辑/删除按钮

**数据接口**：
```
GET    /api/v1/admin/exercises
POST   /api/v1/admin/exercises
PUT    /api/v1/admin/exercises/{id}
DELETE /api/v1/admin/exercises/{id}

GET    /api/v1/admin/achievements
PUT    /api/v1/admin/achievements/{type}
```

### 页面 5：数据统计

**布局**：统计维度选择（左侧 Tab 切换） + 图表区域（右侧）

**统计维度**：
1. **用户画像**：性别饼图、年龄分布柱状图、健身目标分布饼图、运动经验分布柱状图
2. **训练行为**：热门动作 Top10 横向柱状图、训练时段分布（0-6, 6-12, 12-18, 18-24）、训练类型分布饼图
3. **器材统计**：用户拥有器材种类分布横向柱状图
4. **留存分析**：折线图，次日/3日/7日/14日/30日留存率
5. **会员转化**：每日新增VIP折线图、会员续费率

**数据接口**：
```
GET /api/v1/admin/statistics/users     → 用户画像数据
GET /api/v1/admin/statistics/training  → 训练行为数据
GET /api/v1/admin/statistics/equipment → 器材分布
GET /api/v1/admin/statistics/retention → 留存数据
GET /api/v1/admin/statistics/vip       → 会员数据
```

---

### 页面 6：系统设置

**布局**：表单式布局，分为多个设置分区卡片

**设置项**：
- **管理员账号**（表格）：用户名、角色(超管/普通)、创建时间、操作(编辑/删除)。顶部"新增管理员"按钮
- **新增管理员弹窗**：用户名、密码、角色选择
- **App 版本管理**：当前版本号、强制更新开关、更新日志文本域
- **公告管理**：公告列表（标题、内容、发布时间、状态），新增/编辑/删除

**数据接口**：
```
GET/POST/PUT/DELETE /api/v1/admin/admins
PUT /api/v1/admin/settings
GET/POST/PUT/DELETE /api/v1/admin/announcements
```

---

### 页面 7：反馈管理

**布局**：顶部筛选 + 反馈列表表格 + 详情弹窗

**筛选栏**：用户搜索 + 状态筛选（全部/待处理/处理中/已解决）+ 日期范围选择

**反馈列表表格列**：
| 列名 | 说明 |
|------|------|
| ID | 反馈ID |
| 用户 | 用户名 |
| 内容 | 反馈内容（截断显示） |
| 分类 | 问题类型 |
| 状态 | 待处理/处理中/已解决 |
| 时间 | 创建时间 |
| 操作 | 查看/删除 |

**点击反馈 → 详情弹窗**：
- 反馈基本信息：用户、内容、分类、状态、时间
- 消息记录：管理员与用户的对话记录
- 回复输入框：管理员可以回复用户
- 操作按钮：更新状态、删除反馈

**批量操作**：
- 批量删除选中反馈
- 批量更新状态

**数据接口**：
```
GET    /api/v1/admin/feedback                     → 反馈列表
GET    /api/v1/admin/feedback/{id}                → 反馈详情
GET    /api/v1/admin/feedback/{id}/messages       → 消息记录
POST   /api/v1/admin/feedback/{id}/messages       → 发送回复
PUT    /api/v1/admin/feedback/{id}/status         → 更新状态
DELETE /api/v1/admin/feedback/{id}                → 删除反馈
POST   /api/v1/admin/feedback/batch-delete        → 批量删除
PUT    /api/v1/admin/feedback/batch-status        → 批量更新状态
```

## 三、全局组件

| 组件 | 使用场景 |
|------|---------|
| 数据表格 | 用户列表、记录列表等，需支持排序、分页 |
| 搜索栏 | 各列表页顶部 |
| 确认弹窗 | 删除、封禁等危险操作 |
| Toast 提示 | 操作成功/失败反馈 |
| 加载骨架屏 | 数据加载中 |
| 空状态 | 列表无数据时显示图标+文字 |

---

## 四、管理员登录

独立登录页：
- 居中登录卡片，App Logo + "管理后台" 标题
- 用户名 + 密码输入框
- 登录按钮
- 与 App 用户体系隔离，使用独立的管理员账号表

---

## 五、权限设计

| 角色 | 权限 |
|------|------|
| 超级管理员 | 全部功能 + 管理其他管理员 |
| 普通管理员 | 查看仪表盘、用户管理、训练数据、数据统计；不可操作系统设置和管理员账号 |

## 六、技术参数

- **设计稿宽度**：1440px（标准桌面）
- **最小支持宽度**：1280px
- **色板**：主色 `#FF6B35`、成功 `#2ED573`、警告 `#FFA502`、错误 `#FF4757`、深色背景 `#1A1A2E`、卡片背景 `#F5F5F5`
- **字体**：系统默认中文字体（苹方/微软雅黑），数字用等宽字体
- **图表库建议**：ECharts 或 Chart.js
